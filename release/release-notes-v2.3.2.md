# SolarSim Pro 2.3.2

- El logotipo elegido para portada y cabecera se conserva al cambiar el nombre de la empresa. La vista previa del editor muestra la misma imagen que la propuesta.
- La plantilla permanente guarda los datos y textos de la empresa emisora, incluyendo pie de página, teléfono, enlaces y logos. Las nuevas propuestas manuales y desde factura IA los heredan sin sobrescribirlos con el perfil de empresa.
- Las plantillas se mantienen entre sesiones y separadas por empresa y organización; no copian los datos particulares del cliente ni los anexos de una cotización anterior. Los documentos existentes conservan su contenido.

Para fijar una plantilla, abre una propuesta con los datos correctos y pulsa **Guardar como Plantilla Futura** una vez. Las nuevas propuestas de esa empresa la usarán.

Distribución Linux y Windows x64 compilada en GitHub. Windows continúa sin firma Authenticode. Este parche no requiere migraciones ni escrituras en la base de datos de producción.
